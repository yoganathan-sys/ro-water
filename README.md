# R-Tech Pure Water Vercel version

HTML/CSS design is preserved. PHP/MariaDB backend is replaced with static HTML/JS + Supabase.

1. Create Supabase project.
2. Run supabase/schema.sql in SQL Editor.
3. Put Project URL, anon public key and admin auth email in js/supabase-config.js.
4. Create admin user in Supabase Authentication > Users.
5. Deploy this folder to Vercel.
6. Test booking, contact and admin.
7. Add Twilio SMS later.
